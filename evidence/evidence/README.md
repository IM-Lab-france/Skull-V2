# Preuves d’exécution

Créer un sous-dossier par identifiant, par exemple
`evidence/SKULL-03.2/RESULT.md`.

Le résumé contient :

- date et machine ;
- commit de départ et commit produit ;
- commandes exécutées ;
- résultats pertinents et fichiers créés ;
- statut `VALIDÉ`, `PARTIEL` ou `BLOQUÉ` ;
- limites et prochaine action.

Ne jamais déposer ici de mot de passe, clé privée, jeton, valeur de webhook,
contenu de `.env`, archive de production ou log brut non relu. Les preuves
volumineuses ou sensibles restent hors Git ; le résumé donne leur emplacement et
leur checksum sans révéler leur contenu.
